## 采集、处理与精度边界

本轮雷达cfg保持成功基线不变：

- 3TX4RX，TDM顺序TX0→TX2→TX1，32 loops，每帧96 chirps。
- 每RX每chirp为256个复数采样，两路600 Mbps LVDS；每record为HSI64字节+ADC4096字节。
- 每帧399360字节（390 KiB），7个DMA描述符；解码IQ393216字节。
- `profile_id=420d0c99e987c5fc`。
- cfg SHA-256：`8eb44d742c1e2d00a314a4d8dcbef45732d359d4d4de2d153b57234948904566`。
- 当前cfg：`verification/20261030_pages_3tx_01/inputs/radar_3tx_hsi_single.cfg`。配置头、manifest和geometry头须由生成器同步产生。
- 原始逻辑视图为 `[loop,tx_slot,rx,sample,I/Q]`，tx_slot对应物理TX `[0,2,1]`。TX归属来自冻结配置和chirp序号，HSI头自身不含TX编号。

距离谱继续按每帧384次FFT的线性功率平均后转dBFS。新增空间处理保留各TX/RX的复数距离FFT，进行32点慢时间Doppler FFT、检测与峰值筛选、TDM相位补偿、名义阵列角度估计，再生成横向波束图和最多32个检测点。处理分片执行，与采集调度及显示确认共存；不在绘图时运行FFT。

本轮性能优化采用有界批处理：空间DSP每批最多256个step，并在每步完成后检查500 μs时间预算；先到步数上限或时间预算即让出，完成或错误也立即结束本批。原有guard在每批入口执行，保留帧身份、所有权、CRC和故障检查；不重复为每个微小step访问控制通道。DSP公式、阈值、数据顺序和输出保持不变，不增加显示刷新周期。500 μs是在step边界检查的预算，不是对单个step的硬中断。性能与共存结果仍以本轮最终板测为准。

当前使用名义阵列，常驻 `UNCALIBRATED / NOMINAL ARRAY`。XYZ有效仅说明数值质量条件通过，允许显示**未标定空间预览**，不证明左右/上下物理方向、角度精度或绝对高度已验证。低相干、角度边界等无效结果保留为候选信息，并显示 `HEIGHT UNAVAILABLE`；不将未知高度填0绘图。仍需实物方向核对、通道相位/幅度及距离偏差标定，才能评价实际空间精度。当前没有跨帧目标跟踪、人数识别或目标分类。

最新完整原始IQ由CPU结果区保留，下一帧采集后更新；128帧历史继续只保存距离谱与摘要，不保存完整复数历史。诊断TX功率是包含DC的ADC平均复功率，不是校准RF功率。

100 ms为有限源帧配置参数，持续模式仍由有限单帧重复采集组成。本轮v1.8冷启动共存窗口实测平均0.665801帧/秒，约1.50秒更新一帧；显示器仍为60 Hz。旧v1.7约0.685帧/秒仅是历史基线，不能当作当前处理链的速率。
