## 维护与恢复

后续只修改界面时，编译 Application `radar_runtime`。无需重新综合 FPGA 或重建 Platform。字体/显示源位于 `radar_runtime/src/display/`；字体许可和固定源在 `third_party/ui_font/`，随工程交付保留。

修改中文后先运行 `tools/generate_ui_font.py`，再构建。`--check` 用于检查已提交字库是否与源码、固定字体一致。字库为 576 个字形、110111 字节只读资产、零 BSS。生成环境记录在 `third_party/ui_font/subset_manifest.json`；重建固件只需已生成头文件，不依赖 Windows 字体或 Python 字体库。

本轮可重复入口位于 `scripts/`：`build_ps_revision.py`、`check_host_incremental.py`、`check_label_placement.py`、`audit_source_delta.py`。`check_ui_zh.py` 是被标签检查调用的底层绘图测试；最终请使用 `check_label_placement.py`。`localize_renderer.py` 是初次汉化编辑记录，不是最终重建或日常构建入口。`startup_v1113/README.md` 说明匹配启动文件与冷启动流程，必须选 `launch_identity_final.json`。
